# VectorGlass Studio

A lightweight vector workspace featuring frosted glass menus over a dark grey design system, modeled after Photopea/Vectorpea layout architecture.

## Repository File Tree
- `index.html` - The workspace view structure.
- `styles.css` - Professional dark gray layout themes featuring blur panels.
- `canvas.js` - Dynamic SVG shape vector compilation engine.
- `ui.js` - Layout interactivity handlers and built-in AdRemover logic switches.

## Features
- **Extra Tools Expanded**: Includes Selection, Rectangle, Ellipse, Line, and Text markup components.
- **Glassmorphic Start Dropdowns**: Semi-transparent, blur background layers for options menus.
- **Built-In Utilities**: Simulates programmatic removal of user interface advertisement containers via a status bar toggle switch.
